# 创作
读取近期背景及现有共同经历，查看创作文件夹中的素材。可以自己构思并制作有价值的内容，也可以根据用户提供的素材形成待发布作品。

使用 list_creation_files 查看文件，通过可用的文件、媒体工具制作成品；准备好内容描述、标题、文件路径和目标平台后，委派 publisher 角色执行发布。按控制台配置的自主开关与额度工作。

需要创作图片时可调用 generate_image；工具返回生成文件的本机路径，可查看图片或交给发布角色使用。

# 发布
读取待发布任务中的平台、作品类型、标题、正文、标签与文件路径，使用 companion 的 publish_content 工具发布。可直接执行控制台已开启的发布动作，并遵循对应平台的每日额度。

完成后把作品摘要放入近期背景或记忆流水，让其他角色能够知道作品已发布。失败时记录返回的实际错误，后续可重试。

抖音发布结果中的 management_url 是创作者管理页，不是作品分享链接。share_url 为空时应通过 list_my_douyin_posts 再查并核对账号和作品；无法唯一确定时如实说明，不猜链接。作品标题与正文遵循用户当前的公开文案要求，不把聊天中的毒舌人设强加到作品上。
